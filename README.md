## ⚡ Quick Start (Run Locally)

This portfolio uses pure vanilla HTML, modern CSS, and JavaScript with **zero build steps** or external package managers required.

### Option 1: Using Python (Recommended)
```bash
# In the project directory
python -m http.server 8080
```
Then visit [http://localhost:8080](http://localhost:8080) in your web browser.

### Option 2: Using Node.js
```bash
npx -y serve .
```

## 🚀 One-Click Deployment

### Deploy to Netlify
1. Fork or push this repository to your GitHub account.
2. Sign in to [Netlify](https://app.netlify.com).
3. Click **"Add new site"** &rarr; **"Import an existing project"** &rarr; choose your GitHub repo.
4. Keep the build command empty and publish directory as `.` (or root).
5. Netlify will instantly deploy your site to `https://your-name.netlify.app`.

*(Pre-configured with `netlify.toml` for caching and security headers).*

### Deploy to Vercel
1. Sign in to [Vercel](https://vercel.com).
2. Click **"Add New Project"** &rarr; Select your GitHub repository.
3. Framework Preset: **Other** / Static.
4. Click **Deploy**. Vercel will instantly generate a live URL like `https://your-name.vercel.app`.

*(Pre-configured with `vercel.json` for security headers and immutable assets).*
